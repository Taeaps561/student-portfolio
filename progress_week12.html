TOPIC 4 • CLOUD DEPLOYMENT
☁️ การขึ้นระบบบนโฮสต์และคลาวด์ (Deploy on Host, Cloud)
สถาปัตยกรรม Production Cloud: Vercel Serverless Hosting + Supabase/Neon PostgreSQL
Zero Downtime CI/CD
🌐 สถาปัตยกรรม Cloud Production
  • Frontend & API: โฮสต์บน Vercel Edge Network เชื่อมต่อกับ GitHub Main Branch อัตโนมัติ
  • Database: ใช้ Supabase / Neon Managed PostgreSQL พร้อม Connection Pooling
  • SSL / HTTPS: เข้ารหัสช่องทางการสื่อสารทั้งหมดด้วย SSL/TLS Certificate มาตรฐาน
  • Environment Isolation: แยก .env.production ไม่เปิดเผย Database Secrets สู่สาธารณะ
🚀 ขั้นตอนการ Deploy สู่ Cloud (Step-by-Step)
  • 1. Cloud DB Provisioning: สร้างฐานข้อมูล PostgreSQL บน Supabase/Neon
  • 2. Prisma Migration: รัน npx prisma db push อัปเดต Schema ขึ้น Cloud DB
  • 3. Vercel Project Link: เชื่อมต่อ GitHub Repo Taeaps561/student-portfolio
  • 4. Environment Injection: ใส่ DATABASE_URL, NEXTAUTH_SECRET, NEXTAUTH_URL
  • 5. Automated Production Build: Next.js คอมไพล์ Static & Dynamic Routes สำเร็จ 100%
