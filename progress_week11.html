⚠️ 4. ปัญหาที่พบและแนวทางแก้ไข (Issues & Resolutions)

ปัญหาที่พบ (Issue) สาเหตุ (Root Cause) แนวทางแก้ไข (Resolution)
1. การเปิด URL ข้ามสิทธิ์
ผู้ใช้สามารถพิมพ์ URL เข้าหน้า Dashboard หรือหน้าอาจารย์ได้โดยตรง		 การตรวจสอบสิทธิ์เดิมทำเพียงฝั่ง Client-side ผ่าน React State ✓ เพิ่ม Server-side Validation: เช็ค session.user.role ผ่าน Middleware/Server Guard หากไม่มีสิทธิ์จะดีดกลับหน้า /login ทันที
2. ข้อมูล Mock ไม่สมจริง
ข้อมูลเริ่มต้นเป็น Placeholder ทั่วไป ไม่สะท้อนบริบท มสด.		 ใช้ข้อมูลตั้งต้นที่ไม่เชื่อมโยงกับหลักสูตรคอมพิวเตอร์และ DevSecOps ✓ ปรับ Database Seeding: สร้างข้อมูลนักศึกษาจริง 7 คน พร้อมทักษะ CCNA, CEH, DevSecOps ตรงตามบริบท มสด.
3. ความเป็นส่วนตัวของข้อมูล (PDPA)
การเปิดเผยเกรดเฉลี่ยหรือเบอร์โทรสู่สาธารณะ		 ไม่มีกลไก Data Masking สำหรับบุคคลภายนอก ✓ ทำ Data Masking: ซ่อนข้อมูลส่วนบุคคลที่อ่อนไหว และเปิดเผยเฉพาะบทบาทที่ได้รับอนุญาต
